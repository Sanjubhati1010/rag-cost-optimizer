# Local LLM and Vector Database Architecture Guide

## ChromaDB Persistent Storage
ChromaDB is an open-source, AI-native embedding database designed for local and production-grade vector search. Using the ChromaDB PersistentClient, embeddings generated by Sentence Transformers are saved to local disk storage (backend/data/chroma_db). This ensures persistence across server restarts without requiring any cloud database subscriptions.

## Cosine Similarity Space for Retrieval
Embeddings generated by normalized models like all-MiniLM-L6-v2 are evaluated using Cosine Distance (`hnsw:space: cosine`). Cosine similarity calculates the cosine of the angle between two multi-dimensional vectors:
- A distance near 0.0 indicates near-identical semantic meaning.
- A distance between 0.1 and 0.4 indicates strong contextual alignment.
- A distance approaching 1.0 or higher indicates semantic divergence.

## Ollama Engine for Local Model Serving
Ollama simplifies running large language models locally by packaging model weights, configurations, and inference runtimes into a unified tool.
- Model: Llama 3.2 3B (llama3.2:3b)
- Default Port: 11434 (REST API at http://127.0.0.1:11434)
- API Endpoint: /api/generate or /api/chat
- Advantage: Complete data privacy, zero telemetry leakage, zero API subscription costs, and offline availability.
